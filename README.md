# ArabiaLauncher

**ArabiaLauncher** is an independent Minecraft launcher designed to provide a simple, smooth, and convenient gaming experience. It handles game downloads, version management, and setup, making it easy to get started with Minecraft.

The project also offers **ArabiaLauncher Portable**, an alternative edition designed to keep Minecraft, Java, and launcher settings together in a single folder for easy portability.

> **ArabiaLauncher is not affiliated with, endorsed by, or officially connected to Mojang Studios or Microsoft.** Minecraft is a trademark of Mojang Studios. This is an independent project.

## Editions

ArabiaLauncher is available in two editions:

| Edition | Description |
| --- | --- |
| **ArabiaLauncher** | The main edition, focused on convenience, automatic downloads, game version management, and using Java installed on your computer. |
| **ArabiaLauncher Portable** | A self-contained edition that keeps the game, Java runtime, and settings together in one folder, without requiring installation or administrator privileges. |

## ArabiaLauncher

The primary edition of the project, designed to make playing Minecraft straightforward. It automatically handles the necessary game files and provides an easy way to manage and launch different Minecraft versions.

It uses an installed or custom-configured Java runtime and stores downloaded game files locally.

## ArabiaLauncher Portable

An alternative for users who prefer a portable setup. The entire game environment is kept alongside the launcher, making it easy to move, back up, or run from external storage.

No traditional Minecraft or Java installation is required for its included environment.

## Multiplayer

Both editions can be used for multiplayer, depending on the server's requirements, game version, network connectivity, and authentication method.

The difference between the editions is how Minecraft is prepared and stored, not whether multiplayer is supported.
